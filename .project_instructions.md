# Mosaikon Housekeeping App

## Overview
Hotel housekeeping management app for Mosaikon hotel in Athens, Greece. Greek language UI. Replaces a paper-based double-sided sheet system.

## Design
- **Colors**: Navy blue `#1e3a5f` primary, slate/grey tones, emerald for IN status, red for OUT status
- **Font**: DM Sans body, Plus Jakarta Sans headings, JetBrains Mono for room numbers
- **Style**: Clean, professional hotel management. Minimal shadows, rounded elements.

### Private Rooms

### Houses/Apartments

## Architecture
- Auth: NextAuth.js credentials, middleware protecting /dashboard and /api/plan/*
- DB: Prisma with DailyPlan, DormBed, RoomStatus, HouseStatus models
- API: /api/plan (GET creates daily plan on demand), /api/plan/update-bed, /api/plan/update-room, /api/plan/update-house, /api/plan/finalize, /api/plan/generate-pdf
- PDF: HTML2PDF API, 2-page A4 layout (page 1: rooms+houses, page 2: dorms)
- Email: Notification sent on finalize to panosbhtip1@gmail.com
- Status cycle: empty → IN → OUT → empty (click to toggle)

## Key Decisions
- Daily plans auto-created when accessed for a date
- Beds shown as clickable circles matching the paper layout
- Houses table has full tracking columns (IN HOUSE, checkout/checkin times, taxi, balance, pax)
- Date picker in header for viewing/editing different days' plans
